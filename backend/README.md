# Backend Implementation of the Ratehub Backend Exercise

## Overview
Backend service that interacts with a TODO frontend.

## Prerequisites
Before running the backend, ensure you have the following installed:
- [Docker](https://docs.docker.com/get-docker/)
- [Node.js](https://nodejs.org/en/)
- [MongoDB](https://www.mongodb.com/docs/manual/installation/) (only required for running tests, otherwise MongoDB is already included inside the Docker image)

---

## **How to Start the Backend and Frontend**
To run the backend, follow these steps:

### **1. Clone the repository**
```sh
git clone https://github.com/diogoverardi/psychic-octo-eureka.git
cd psychic-octo-eureka
```

### **2. Start the Backend (Using Docker)**
```sh
git pull  
git checkout backend -- 
cd backend
docker compose up -d  # Start the Backend and MongoDB containers
```

### **3. Start the Frontend**
```sh
cd ../frontend
npm install 
npm start  # Start the React app
```

Once both backend and frontend services are running:
- The **backend** API will be available at `http://localhost:3001/api`
- The **frontend** will be available at `http://localhost:3000`
- By this point the user should be able to View, Add, Edit and Remove items (TODO) by acessing `http://localhost:3000`.

---

## **Running Tests**
Unit tests for the backend are located in the `/backend/tests` folder. **These tests run outside of Docker** and require MongoDB to be installed locally.

### **1. Install Dependencies**
```sh
cd backend
npm install
```

### **2. Install MongoDB Locally using Homebrew**
```sh
brew tap mongodb/brew
brew install mongodb-community@6.0
brew services start mongodb-community@6.0
```

### **3. Run Tests**
Make sure to **stop the Docker containers** to avoid port conflicts before running the tests:
```sh
docker compose down  # Stops backend and MongoDB containers
npm test  # Run all test cases
```

### **4. Test Data**
To check the data generated by the Unit Tests in MongoDB:
```sh
mongosh  # Open MongoDB shell
use todo  # go to the database
db.todos.find().pretty()  # To view all the Todo/Items
db.todos.deleteMany({})  # Delete all records (useful after running tests)
```

---

## **Notes**
- The **backend** and **MongoDB** run inside Docker, but **tests require a local MongoDB instance**.
- If switching between **Docker-based MongoDB** and **local MongoDB**, ensure only **one is running at a time** to avoid conflicts, specially with the `3001` Port.

---

## **Troubleshooting**
- **Port Already in Use**  
  Ensure no other processes are running on port `3001` (backend) or `27017` (MongoDB).
